# Sales Analytics Dashboard

Projeto de análise de dados de vendas utilizando PostgreSQL, SQL e Power BI.

## Objetivo

Desenvolver uma análise comercial através de consultas SQL e criação de indicadores para acompanhamento de desempenho.

## Tecnologias

- PostgreSQL
- SQL
- Power BI
- DAX

## Etapas do projeto

- Exploração dos dados utilizando SQL
- Criação de queries analíticas
- Desenvolvimento de indicadores comerciais
- Construção de dashboard interativo no Power BI
